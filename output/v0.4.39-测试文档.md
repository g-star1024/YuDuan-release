## 2. 根因（代码级铁证）

### 2.1 设置中心布局
- 修改密码面板三输入框仅 `placeholder` 无 `<label>`，输入后字段含义消失；`form-col` 锁 `max-width:340px` 在宽卡留白（`pages.tsx:1398-1411` / `styles.css:1059`）。
- 数据备份裸 `<table>` 继承全局 `tbody tr{cursor:pointer}` 让行像可点实际不能；双重缩进（卡片 24px + `th` 16px）（`pages.tsx:3557` / `styles.css:809-840`）。
- 中枢配置信息区散文式 `·` 拼接（窄卡换行错乱）；`.nested`/`<h3>` 在 CSS 无规则，分组标题用浏览器默认 h3（`pages.tsx:3706-3714` / `styles.css` 无 `.nested`）。

### 2.2 报警（后端真 BUG）
- `PostgresStore.AddAlert` 先 `UPDATE` 同 `device+type` 未读行又**无条件 `INSERT`** → 去重失效，每次合规评估插一条相同告警（`postgres.go:413-432`）。`MemStore` 是对的（命中直接 `return`），仅 PG 路径暴露 → 重复合规告警 + 99 红徽章。
- `rc_timeout`（主端空闲超时，预期断开）被 `severityOf` 默认 `warning` 弹告警（`wave2.go:330` + `severityOf:362-371`）。

### 2.3 副端连不上（⚠ 本节已按第二十二轮 Windows 实机报告勘误，2026-11-10）
- relay 即 Hub 自身在两条 WS 间对拷帧（`hub.go:1067 relayToViewer`），无独立转发服务。
- **本节原文结论有误，已作废**：原文写"根因是副端 `YUDUAN_HUB` 未指向隧道后的 Hub，设为操作项即可"。Windows 实测（5 次尝试 + 1 次对照实验）证明该配方在 Windows 上无可执行入口，M8 判为失败。
- **勘误后的真实根因链**（已逐行复核源码，详见 `output/v0.4.40-测试文档.md` §2）：
  1. `YUDUAN_HUB` 确是唯一端点开关，但 `main.rs:2134-2141` 只在**服务进程启动那一刻**读一次并固化进内存局部变量 `url`；`main.rs:2195` 仅在无显式端点时做 UDP 发现漂移。
  2. `agent-config.json` **只存 DPAPI 加密的 `hmacSecret`+`enc`**（`config.rs:131-135`），全源码不存在任何持久化的 hub 端点。
  3. `setup.rs:26-31` 的 `DEPLOY_ENV_NAMES` 含 `YUDUAN_HUB`，`--setup`/安装会 `reg delete` **清掉它** → 服务回落 UDP 发现模式，把本地中枢广播的 wss 地址固化。
  4. 改机器级 env 后**服务从未真正重启**（报告 Attempt 3：`sc stop` 返回 win32 1052、PID 未变）；Windows 服务继承的是进程创建时刻的 env 快照 → 持旧 `url` 的进程一直连本地。
  5. 封 UDP 18242 的对照实验只是让 `discover_ws` 返回 `None`、`main.rs:2196` 不进入，从而**冻结** `url`，并不证明"存在持久化端点"（假两难）。
  - 结论：**P1-1（缺可靠的远端端点入口）与 P2-5（服务不接受 STOP，1052）是同一根因链的两面**，必须合并修；v0.4.40 已按此落地 `--set-hub` + 运行期重载 + 优雅停止。
- 报告原结论"Windows 副端不读 `YUDUAN_HUB`、端点来自 `agent-config.json` 持久化值"经源码裁决为**错误**（现象真、归因错）；本勘误为交付后的正式更正。

### 2.4 主端无文件日志
- GUI 启动无文件 appender，`println!`/`stderr` 仅落 macOS 系统日志，不便排查 → `lib.rs run()` 开头 Unix `dup2` 重定向 stdout/stderr 到 `~/Library/Logs/YuDuan/main.log`（best-effort，绝不 panic）。

### 改动清单
- `dev/internal/store/postgres.go`：`AddAlert` 改先查后插；`migrate` 加幂等清理重复未读告警 SQL。
- `dev/internal/hub/wave2.go`：`severityOf` 加 `AlertRCTimeout → info`。
- `main/src-tauri/src/lib.rs`：文件日志重定向（`dup2`）。
- `main/src-tauri/src/media_session.rs`：`got_ready` 区分 Close 文案。
- `main/src/pages.tsx` + `styles.css`：修改密码 label；备份表去 `cursor:pointer`/双重缩进/操作列 72；中枢配置 `.kv` 网格 + `.nested` 标题；告警页 10s 自轮询；折叠态迷你标签；`form-col` 去 340px 锁。
