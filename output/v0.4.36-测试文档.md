### 1.1 根因与修复映射

| 编号 | 现象（实测矩阵） | 根因 | 修复 |
|---|---|---|---|
| #1（增强） | `port5432-occupied` 用例：5432 被**非 PG** 监听占用 → 脚本走「端口占用但非标准安装→跳过自动安装」分支 → 干净机一键 0% 成功（#A 修复后仍会在此场景失败） | `register-task.ps1` 便携 PG 硬编码 `$PG_PORT=5432`，5432 被占即放弃自动安装 | 新增 `-PgPort` 参数（默认 0=自动）：① 5432 空闲→用 5432；② 5432 被非 PG 占用且本机无 `yuduan-pg` 服务→自动选 `5433..5442` 中首个空闲端口，`$PG_PORT` 重赋后贯穿 `Install-OwnPg`/`Start-OwnPg`/`Grant-YuduanRole`/DSN；③ 显式 `-PgPort >0` 须空闲（被占则原因码 `PG_PORT_BUSY` 中止）；④ `-DbDsn` 优先，本参数仅影响自动就绪路径 |
| #5（增强） | 失败仅中文 WARN 段落，无结构化原因码，外部编排只能靠进程 + 登录探测判定根因 | 各降级/失败分支仅 `Write-Host`，无机器可读标识 | 新增脚本级 `$script:DeployReason` + `Fail-Deploy` 统一出口；在关键失败点赋值原因码：`PG_AUTH_REQUIRED`（本机 PG 需口令且非交互）、`PG_ROLE_EXISTS_NO_PWD`（yuduan 角色已存在但口令未知）、`PG_PORT_BUSY`（显式端口被占）、`PG_INSTALL_FAILED`（便携 PG initdb/服务/启动失败）、`DSN_MISSING`（最终无 DSN 且非交互/交互放弃）、`SELFCHECK_FAIL`（自检失败）；最终中止统一 `exit 1` |
| #6（增强） | 一键部署结果仅靠退出码 + 控制台文本，外部编排难消费 | 无机器可读产物 | 新增 `Write-DeployResult`：成功时（`$allPass`）写 `{success:true, hub_port, reason:"OK", ...}`；`Fail-Deploy` 写 `{success:false, reason:<CODE>, detail}`；落盘 `installDir\deploy-result.json`（UTF-8，单行紧凑 JSON）；`deploy.bat` 末尾 `type` 输出该文件 |

### 1.3 发布仓 CI 修复（commit `ba9ab36`）

v0.4.36 首轮发版（发布仓 tag→`21c9f6a`）连续两次 CI run（`42640167046` / `42644712412`）均 `build-macos` 被 macOS hosted 池 **cancelled**（0 失败步骤）→ `publish` 被 **skipped**（failure_reason=None）→ 零 Release。

**根因**：GitHub Actions 在 `needs` 中任一 job 被 `cancelled` 时会**无条件跳过**下游 job，且下游 `if:` 写 `needs.X.result=='cancelled'` **无法救回**（实测两次均 skipped）。原 `publish` 把 `build-macos` / `build-agent-linux-arm64` 列入 `needs`，致 mac 池故障期整条发布被拖死。

**修复**（`release-build.yml` `ba9ab36`）：① `publish.needs` 仅留「必须成功」的关键 job（`build-windows` / `build-hub` / `build-linux-agent` / `build-linux-main`）；② 新增「等待 build-macos 终态」步骤——轮询当前 run 的 `build-macos` job（`GET /actions/runs/{id}/jobs`），`success`→下方 download 取到 mac 产物（15/15），`cancelled/failure/skipped`→跳过 mac（`::warning::` 降级，13 个非 mac 产物照发），轮询设 90 次×20s 上限防死等；③ `build-macos` / `build-agent-linux-arm64` 仍独立构建，其产物由 `publish` 内 `if [ -n ... ]` 目录守卫处理缺席。

> 实测：重打 tag→`ba9ab36` 后 run `42653785295` 全部 7 job success（含 `build-macos` 本轮回合健康），`publish` success，Release `439373735` 15/15 资产落地。修复后即便 mac 池再次 flake（cancelled），`publish` 也不再被跳过。
