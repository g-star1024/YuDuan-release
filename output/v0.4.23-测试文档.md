## 三、实机验收指引

### A. 主端徽章（问题1）
- A1 远控会话中拖动右上角徽章 → 可拖到画面任意位置、不出画面边界；拖后点击仍可正常展开/收起 QoS 面板（拖动与点击互不误触）
- A2 点徽章内「–」→ 收起为小圆点；点小圆点 → 展开完整徽章
- A3 重启主端 → 徽章位置与收起态保持（localStorage 持久化）

### B. 一键部署防挂死（问题2，第十四轮问题1）
- B1 **复刻挂死场景**：MedCRM 嵌入式 PG（5432 被占、非标准目录）机器上双击 deploy.bat → 应在 PG 复用预检失败后**立即**打黄色 WARN（「本机 PG 需要口令认证…非交互模式跳过复用」+ 处置指引）并继续部署，**全程无 300s 卡死**
- B2 `deploy.bat -DbDsn "postgres://yuduan:密码@127.0.0.1:5432/yuduan?sslmode=disable"` → DSN 经提权重启链透传，register-task.ps1 直接写入 hub.env（不再隐窗询问）
- B3 干净机（无 PG、有公网）deploy.bat → 自动下载 EDB 便携包装 yuduan-pg → 自动建号写 DSN（v0.4.22 既有链路回归）
- B4 干净机（无 PG、无公网）deploy.bat → 下载快速失败 → 明确 WARN → 内存模式部署完成（不挂死）

### C. 副端就地升级不删服务（问题3，第十四轮问题2）
- C1 **复刻 1072 场景**：旧版副端服务+远控助手运行中，重跑新版 `--setup` → 输出应出现「检出既有服务且指向同一安装目录：就地升级（替换二进制 + 重启，不删服务、无 1072 风险）」，**全程不出现「标记删除」等待日志**，升级一次通过
- C2 就地升级后 `--status`：服务 RUNNING、ver=新版、重新 claim 密钥成功
- C3 首装（无旧服务）与目录迁移（旧服务指向异目录）→ 仍走「删旧建新」全量路径（[1/6] 已移除旧服务…），1072 自动重试兜底保留
- C4 升级日志确认无 `QueryServiceConfigW` 报错路径触发（异常时自动退全量路径，不阻断安装）

## 四、遗留与观察

- MedCRM 等 trust 免密非标准 PG 的**复用**在交互模式（手工跑 register-task.ps1）仍会询问口令一次；非交互（一键）直接跳过复用——若需自动复用 trust 库，可后续加 `-PgSuperUser` 参数指定连接用户（当前 `psql -U postgres` 在无 postgres 角色的嵌入式 PG 上必失败，属已知边界）
- 内存模式回退时有黄色 WARN + `-DbDsn` 指引（符合报告建议「回退内存模式+黄色警示」）
- 环境偏差（Win11 LTSC 单机、保活模拟、主端 GUI 未端到端）维持记录
