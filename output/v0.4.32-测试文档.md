### 1.1 设备证明接线设计（§9.2 中枢侧，commit `51cca55` 落地）

- **下发挑战**：`handleAgentWS` 生成 `nonce` + `chTS = time.Now().Unix()`，挑战 payload 携带 `TS: chTS` 与 `RequireAttest: h.attestRequire`（默认 false）。
- **握手校验**：HMAC 校验 `ap.Nonce == nonce && VerifyRegisterAuth(...)` 通过后，若 `attestRequire` 为真则进入 §9.2 校验块：
  1. 三字段任一为空 → `agent_attest_failed`（缺字段）拒绝；
  2. 白名单非空且 `measurement` 不在 `attestTrustedMeasurements` → `agent_attest_failed`（白名单未命中）拒绝；
  3. `crypto.VerifyAttestation(pubkey, sig, nonce, token, measurement, chTS)` 失败 → `agent_attest_failed`（Ed25519 验签失败）拒绝；
  4. 全部通过 → `attestedNow = true`。
- **注册一致性**：`TypeRegister` 分支、token 一致后新增公钥一致性校验——`attested && p.AgentPubkey != apPubkey` → `attest_pubkey_mismatch`（注册公钥与设备证明公钥不一致）拒绝，防换身份。
- **落库**：`store.Device{AgentPubkey, Attested}`；`MemStore.Upsert` 守卫旧副端重连不得清空既有公钥/证明态；PG `deviceCols` 加 `agent_pubkey,attested`、`Upsert` 占位符扩至 `$1..$27`、`rowToDevice` 索引 26/27、`migrate()` 幂等加两列（`IF NOT EXISTS`）。
- **灰度开关**：`NewHub` 读取 `YUDUAN_ATTEST_REQUIRE`（helper `envBool`）+ `YUDUAN_ATTEST_TRUSTED_MEASUREMENTS`（helper `parseTrustedMeasurements`），默认关闭。

### 1.2 主端展示列（commit `b0fd8ef`）

- **后端字段**：`handleDevices` 返回 `h.store.List()`（`[]store.Device`），JSON 已带 `agent_pubkey`（omitempty）+ `attested`（始终输出）。
- **Rust 桥**：`hub_client.rs::Device` 新增 `agent_pubkey: String`（`serde rename "agent_pubkey", default`）+ `attested: bool`（`default`），重新序列化到前端。
- **前端类型**：`api.ts::Device` 新增 `attested?: boolean` + `agent_pubkey?: string`。
- **表格列**：设备台账表头新增「证明态」「公钥指纹」两列；`AttestBadge`（已证明→`pill ok` / 未证明→`pill off`）+ `fmtFingerprint`（长 hex 截断「前 8 … 后 6」，完整值放 `title`）。
- **详情卡**：新增「证明态」徽章 + 「公钥指纹」完整 hex（带 `CopyBtn` 一键复制）。
- 默认 LAN（未启用证明）：旧副端落 `attested=false` / `agent_pubkey=""` → 表格显示「未证明 / —」；启用 `YUDUAN_ATTEST_REQUIRE=1` 且副端合规 → 「已证明 + 指纹」。前端无需门控，渲染语义与后端一致。
