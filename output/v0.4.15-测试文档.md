# 御端 YuDuan v0.4.15 测试文档

> 测试重点：⭐ **Windows 副端远控双进程修复（v0.4.14 顺延项正式落地）**。Rust 副端服务（Session 0）改用 WTS 拉起用户会话助手 `--rc-helper`，助手在活动用户会话内真实 GDI 抓屏 + SendInput 注入，经 127.0.0.1 回环 TCP 中继帧与输入；无活动会话/锁屏时 `rc_ready` 带明确失败原因。回归保持 v0.4.14 的台账部分更新、viewer 403、就绪探针、UI 治理。

### 本版变更摘要

| # | 问题来源 | 修复内容 |
|---|---|---|
| 1 | v0.4.14 报告 ④远控合成彩虹帧（根因 Session 0 直抓） | **Rust 副端双进程远控**：`rust/agent/src/rc.rs` 新增 `#[cfg(windows)] rc_helper` 模块 + `main.rs` 新增 `--rc-helper` 入口。`start_rc` 在 Windows 改用 `rc_helper::start_for_session()`：①`WTSGetActiveConsoleSessionId` 取活动会话；②`WTSQueryUserToken`+`DuplicateTokenEx`(primary)+`SetTokenInformation`(TokenSessionId) 复制令牌；③`CreateProcessAsUserW` 拉起自身 `--rc-helper <port> <sid>` 子进程（运行于用户会话，`winsta0\default` 桌面）；④服务监听 `127.0.0.1:0` 接受助手回环连接。助手线程内 `capture_jpeg()` 真实抓屏、上行 `MSG_FRAME` 帧；服务转发 `MSG_INPUT` 输入由助手 `inject_input_windows()` 注入。非 Windows 平台 `relay_frame()` 回退原 `capture_jpeg()` 路径，行为不变 |
| 2 | 远控失败原因不可读 | `start_for_session()` 失败返回 `Err(reason)`：`no_active_console_session` / `cannot_acquire_user_token` / `session_locked` / `token_duplicate_failed` / `relay_listen_failed` / `launch_helper_failed` / `helper_connect_timeout`；`start_rc` 据此 `send_rc_ready(...,false,reason)` 上报，主端 viewer 展示明确失败原因 |
| 3 | （回归）macOS/Linux 副端远控 | 非 Windows 平台 `relay_frame()` 仍走原 `capture_jpeg()` 采集、`apply_input` 本地 `inject_input_windows()`，行为与本版前一致；120 个单元测试全绿（含 rc_media / 密钥映射 / 完整性自检） |

## 2. 环境准备

1. 下载并部署 **YuDuan-hub_v0.4.15_windows_amd64.zip**（就绪行语义同 v0.4.14：回环 HTTP 登录探针，出现即代表可登录）。
2. **Agent-A**（关键测试机，Windows）：卸载旧副端后安装 **YuDuan-agent_v0.4.15_windows.exe** 并注册。保持**已登录桌面会话、不锁屏**。
3. **Agent-B**：同版本安装注册，用于多设备回归。
4. 主端安装 **YuDuan-console_v0.4.15_windows_x64.exe**（macOS 用对应 dmg）。
5. 建议先跑一次 `cleanup.ps1`（v0.4.9+ 附带）清理旧实例，避免旧 hub 占用 8080。

## 3. 新功能测试用例

### 3.1 ⭐ Windows 副端远控（本版核心，正式测试）

| 步骤 | 操作 | 预期 |
|---|---|---|
| 1 | 主端→设备→对 **Agent-A（Windows）** 发起远控 | viewer 显示**真实桌面画面**（非黑屏/非彩虹帧）。副端日志出现 `远控助手已拉起 sid=.. pid=.. port=..` |
| 2 | 鼠标移动/点击、键盘输入 | Agent-A 桌面**实际响应**；坐标落点准确（DPI-aware 已设，`set_dpi_aware_windows` 在 `main` 入口先于任何采集/注入调用） |
| 3 | **锁屏 Agent-A** 后再次发起远控 | viewer 显示**明确失败原因**（如「会话已锁定」），副端 `start_for_session` 返回 `session_locked` 并 `send_rc_ready(false,"session_locked")` |
| 4 | 注销/无活动控制台会话时发起远控 | viewer 显示失败原因（`no_active_console_session`），不卡死在等待 |
| 5 | （回归）macOS 副端 Agent 远控 | 行为不变，正常显示真实画面 |
| 6 | （回归）Linux 副端 Agent 远控 | 行为不变，正常显示真实画面 |
| 7 | 停止远控 | 服务 `rc_helper::stop()` 关流 + `TerminateProcess` 终止助手进程，日志 `远控助手已停止 pid=..`；再次发起可正常拉起新助手 |

## 6. 已知限制 / 观察点

| # | 项 | 说明 |
|---|---|---|
| 1 | **Windows 锁屏远控** | 锁屏会话下 WTS_IS_LOCKED 检出后拒绝远控（安全设计，非缺陷）；解锁后即可正常远控 |
