## 5. 不纳入本版的事项与理由（待用户拍板）

- **F-07（UDP 18242 写死）**：报告 §4 记录隔离 public 实例因生产实例占用 18242 而绑定失败。改动牵涉 hub + Rust 副端 + 主端 + 部署脚本 + 协议文档五处联动，只改 hub 会协议错配；属架构改造，应单列一批排期。
- **F-09（PE 版本资源为空）**：hub / agent / acme / ca 四个 Windows exe 的 `ProductVersion`/`FileVersion` 为空（主端为 0.4.27）。需 CI 加 goversioninfo / rcedit 资源步骤，且 Rust 侧 rustc 直编不能用 build.rs；属发布流水线改造。本版主端版本串已 bump 到 0.4.28。
- **副端 `--setup` 中文输出**：报告 §2 判定 `EXIT=0`、服务 RUNNING、claim 成功，为宿主 PS 5.1 控制台编码问题，非产品缺陷。但全仓 Rust 副端有数十处中文 `eprintln!`（服务运行时日志亦走 stderr），改走 stdout 会改变服务日志采集约定，需单独评估；且 `register-task.ps1` 不调用 `--setup`（用户手工执行），不影响官方一键部署链路。
- **macOS 无一键 `-Public` 入口**：v0.4.27 文档 §5 已登记，本版仍未处理。
