核心能力

一台管理面板，覆盖终端运维全链路

中枢 + 主端 + 副端三组件协同，IT 运维在主端集中管理千台级企业终端。

设备资产台账

硬件、软件、网络与安全状态自动采集，形成持续更新的资产台账；资产变更全程留痕，时间线可追溯每一台设备的配置演化。

远程协助

屏幕查看与控制、独立视窗、会话文件传输与录像；支持远端强制提示与权限分级审批，协助过程全程可审计。

软件分发

内置软件仓库，向指定终端批量静默安装；分发状态实时追踪，安装成功、失败、等待一目了然，无需逐台操作。

合规与告警

合规基线扫描持续评估终端安全状态；告警支持多通道外送：Webhook（HMAC-SHA256 签名 + 幂等 ID）、企业微信、SMTP 邮件。

安全内建

RBAC 三角色权限、审计链 + 库外防篡改锚、设备密钥 attestation、副端卸载密码门、HMAC 签名防重放，安全不是插件而是底座。

一键部署

部署器一键拉起中枢，-SelfTest 自检快速定位环境问题；端口独占绑定与回退、公网模式 TLS + ACME 证书自动续期。

系统架构

三组件协同，链路全程加密

主端（管理客户端）— 中枢 hub（服务端）— 副端（终端驻留服务），最小化攻击面，全链路 TLS + HMAC 签名。

WebSocket + TLS 传输加密 HMAC 签名 防篡改防重放 心跳 30s 在线状态感知 中继远控 屏幕查看与控制 PostgreSQL 持久化存储
快速部署

三步上线，当天可用

从空服务器到千台终端纳管，一条最短路径。

① 中枢一键部署

解压发布包运行部署器即可：Windows 计划任务 / macOS launchd / Linux systemd。内置 -SelfTest 自检，配置问题当场暴露；公网模式自动签发并续期 TLS 证书。

② 副端零配置注册

在员工电脑上安装副端服务（Windows Service / macOS launchd / Linux systemd），UDP 自动发现中枢，无需手工填写服务器地址；安装后自动完成设备密钥注册与 attestation。

③ 主端登录接管

IT 运维在主端登录中枢，终端在线状态、资产台账、软件分发与告警事件即时报表呈现；按角色授权后即可发起远程协助或批量下发软件。

安全设计

安全内建于底座，而非事后补丁

从传输、身份到审计，每一层都有明确的防线。

RBAC 三角色

管理员 / 运维 / 审计员分级授权，高危操作（如远控、分发）按角色约束。

审计链防篡改

操作审计形成哈希链，并定期写入库外 append-only 锚文件，离线即可核验完整性。

传输签名防重放

全链路 TLS 之上叠加 HMAC 请求签名与幂等 ID，防篡改、防重放。

副端卸载密码门

员工无法随意卸载或删除副端服务，退出需持有卸载密码，保障纳管覆盖。

设备密钥 attestation

每台副端持有独立设备密钥并上报二进制度量，主端可见设备「证明态」与公钥指纹。

会话安全

服务端会话表统一管理登录态，支持吊销与空闲超时，离岗即失效。
